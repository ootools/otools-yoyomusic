# 第三方来源与许可证

## YoYoMusic（悠悠乐听）

- 来源：`https://github.com/ijry/YoYoMusic`
- Go 版布局参考：`main` 的 `0e9b006`（v0.2.8）。
- Canvas 动效与信号引擎来自 `tauri` 分支；移植文件头保留具体来源与注释。
- `web/src/ui/icons.tsx` 基于 Go `internal/ui/icons.go`；`web/src/viz/piano.ts` 基于 Go `internal/ui/viz.go`。
- Copyright © 2026 xyito。AGPL-3.0-or-later，完整条款见根目录 `LICENSE`。
- 本插件对应源代码包含在 `.oplg` 的 `source/` 目录（web、scripts、配置、依赖锁文件）。源码不包含用户音乐、node_modules 或开发验收夹具。

## OTools plugin SDK

`web/src/bridge/host-file-tree.ts` 基于 `otools-plugin-sdk/src/host-file-tree.ts` 的宿主 DOM 文件树，增加多选、导航竞态保护与皮肤适配。
